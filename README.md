# Raha Cloud Homebrew Tap

Homebrew casks for [Raha Cloud](https://github.com/rahacloud) tools.

```sh
brew tap rahacloud/tap
```

## Available

| | |
| --- | --- |
| [`darkubectl`](https://github.com/rahacloud/darkubectl) | kubectl-like CLI for the Hamravesh Darkube platform |

```sh
brew install rahacloud/tap/darkubectl
```

## How this tap is updated

Casks here are published automatically by [GoReleaser](https://goreleaser.com) when a project cuts a release — do not edit `Casks/` by hand.
